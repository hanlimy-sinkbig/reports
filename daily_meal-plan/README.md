# daily_meal-plan — 이번달 식단 추천

매일 06:15(KST) GitHub Actions가 이번달·다음달 식단 달력과 오늘의 음식 뉴스 10개를 게시합니다.

- 웹: https://hanlimy-sinkbig.github.io/reports/daily_meal-plan/ · PDF `latest.pdf` · 단축어용 `latest.json`
- 화면: ① 테마 버튼(#고기 #야채 #국물 #영양식 … 27개) ② 달력(하루 3가지, 🍳집밥·📦밀키트·🛵배달) ③ 오늘의 음식 뉴스 10개(제목만)
  - 테마를 누르면 그 테마 메뉴로 짠 달력으로 바뀌고, 한 번 더 누르면 전체로 돌아옵니다.
  - 메뉴를 누르면 레시피(재료·순서), 밀키트 주문 방법(쿠팡·컬리·네이버쇼핑 검색), 배달 음식점(대표 프랜차이즈·동네 지도 검색)이 나옵니다.
  - 전체 식단은 하루 "국·찌개 + 고기·생선 메인 + 별미"로 짜고, 금·토와 가끔은 배달 메뉴가 한 칸 들어갑니다. 제철 메뉴가 더 자주 나옵니다.
- 같은 달·같은 테마는 매일 다시 만들어도 식단이 같습니다. 메뉴 목록을 바꾸면 그다음 실행부터 새로 짜입니다.
- PDF: 1쪽 이번달 달력(전체), 2쪽 오늘의 추천 레시피 + 뉴스.

## 고치는 곳 (`meal_data.py`)
- `DISHES` — 메뉴·레시피. `kit=True`면 밀키트 안내, `dl="키"`면 배달 안내, `season=[월…]`이면 제철 메뉴.
- `THEMES` — 테마 버튼. `제철`·`밀키트`·`배달맛집`은 자동 계산.
- `DELIVERY` — 배달 분류별 대표 프랜차이즈와 검색어. `AREA` — 지도 검색에 붙는 동네 이름.

로컬 실행: `pip install -r requirements.txt && python meal_plan.py --outdir out/daily_meal-plan` (`--demo`, `--date YYYY-MM-DD` 가능)
